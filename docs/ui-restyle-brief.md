# BootAgent 视觉重构设计简报（阶段 0）

> 状态：随 [ADR-010](decisions/ADR-010-visual-restyle-swiss-blueprint.md) 一同评审。
> 本文是唯一的取值来源：调色板、字体、签名元素规格都以此为准，
> 比稿 HTML 与后续 `tokens.css` 改造从这里抄值，不自行发明。
> 所有对比度为按 WCAG 2.x 相对亮度公式实算，非目测。

## 1. 方向一句话

**制图纸上的瑞士排版，蓝图作签名。** BootAgent 做的事是「把一台机器按图纸接线」——
Agent、Provider、Profile 之间的关系天然是接线图。界面主体是安静的瑞士式网格与字阶，
个性集中在一层克制的工程制图语言：引出线、图签、尺寸标注。暗色模式反转为蓝晒
（cyanotype）底，蓝图的两种物理形态恰好对应明暗双色板。

现有陶土色不删除，降级为品牌印记色：只出现在应用图标、启动画面、关于页。
`brand/` 资产不重绘。

软底色（`*-soft`）一律取对应色相的 8% 不透明度等效实色，仅作底、不作边界。

**危险与主操作的色相分离是本次换色的硬收益**：蓝 `#20618e` 与红 `#b0301c` 相距半个
色环，替代现状 `#a94623` vs `#a32b1d` 的同族困境。

### 2.3 品牌印记色

`--brand: #d96e49`（亮）/ `#e4855c`（暗）保留原值，但从「可操作强调」的岗位上撤下：
允许出现的位置逐条列举为——应用图标、启动画面、关于页 logo、导出文件的封面标识。
界面控件、链接、选中态一律不得使用。

## 3. 字体

三个角色，全部 SIL OFL，可打包进产物、许可证走 `scripts/generate_third_party_licenses.py`
入 NOTICE。产物内本地打包，不发外部字体请求（比稿 HTML 例外：预览用 CDN，已在文件内注明）。

| 角色 | 字体 | 理由与用法 |
| --- | --- | --- |
| Latin 正文与标题 | **IBM Plex Sans**（400/500/600） | 瑞士式纪律：一族字体靠字重与字号承担全部层级，不引入第二族展示字。Plex 本身就是为工程语境设计的 grotesque，与制图方向同源。标题 = 600 + 收紧字距，不另选花哨展示体。 |
| 注记与数据 | **IBM Plex Mono**（400/500） | 蓝图注记声：版本号、模型 ID、路径、图签、引出线标签全部走 mono。与 Plex Sans 原生同族配对。 |
| CJK | **Noto Sans SC**（400/500/700，子集化） | 覆盖完整、OFL、与 grotesque 的灰度匹配良好。构建期按实际用字子集化控制体积。比稿在未加载时回退 PingFang SC，形态相近。 |

字阶（自 13px 基准，1.25 比例取整）：13 / 15 / 17 / 21 / 26 / 33。行高：正文 1.6，
标题 1.25，mono 注记 1.5。中英混排场景（Agent 名 + 中文说明）以 15px 为主工作字号。

## 4. 签名元素规格（只此三处）

签名层的预算刻意花在一个地方：**制图注记语言**。三处之外不得出现，扩散需重开 ADR。

### 4.1 总览页（比稿 Tile A 所示）

- **网格纸底**：`--page-bg` 上以 `--wire` 画 8px 细网格、32px 主网格
  （opacity 分别约 0.5/1.0 倍的 `--wire`）。卡片（sheet）内部无网格——纸在图下。
- **图签（title block）**：页头右侧一个 1px 边框小表格，mono 排印：
  `SHEET 01 · ENVIRONMENT OVERVIEW / REV <git 短哈希> · <日期>`。
  REV 用真实构建哈希——图纸修订号即软件版本，这个双关是功能性的，不是装饰。
  （比稿初版曾含 `SCALE 1:1` 第三格，自评后删除：不承载信息的图签格是装饰噪声。）
- **分区字母**：三个区段按制图图区惯例编号 `A 命令行 Agent`、`B 桌面 Agent`、
  `C 运行时`；每行 Agent 携带小号 mono 位号（A1…A9、B1…B3），对应制图的元件位号。
  位号同时是行内锚点，未来漂移徽标可引用「A7 检测到外部修改」。
- **引出线（leader line）**：Agent 行右侧至其 Provider/模型注记之间画 1px 折线，
  起点一个 3px 空心圆端子。已配置 = 实线 `--accent`；未配置 = 虚线 `--wire` 指向
  「未配置」。这是「接线图」隐喻的最小可视形态。

### 4.2 向导 review 步 / 激活前 diff 预览

尺寸标注样式：`|— 键名 · 旧值 → 新值 —|`，两端 tick、mono 排印、变更值 `--accent`。
（对应优化方案 M2 的 diff 预览，视觉规格在此锁定。）

### 4.3 空态

网格纸底上一个 1px 虚线制图框，框内居中一行说明 + 一个主按钮。不配插画。

## 5. 组件基调

- **零软阴影预算**：卡片与面板靠 1px 墨线（`--border`）与底色差分层，`--shadow-window`
  仅保留给真正浮起的窗口/对话框一级。
- 圆角收紧：`--radius-control: 4px`、`--radius-panel/card: 6px`、`--radius-window: 10px`
  ——制图语言容不下 12px 的软角。
- 状态徽标：方角（2px）、1px 边框、mono 11px、色相点 + 文字（不只靠颜色）。
- 按钮：主要 = `--accent` 填充白字；次要 = 1px 墨线透明底；危险 = `--red` 文本 + 边线，
  确认类危险操作才用红填充。
- 动效：一组编排（页面载入时图签与分区标题先落、行随后 40ms 级联；引出线在行
  hover 时从端子向注记「画出」150ms）。`prefers-reduced-motion` 下全部关闭。

## 6. 已比稿的备选：新粗野主义（Tile B，未采纳）

同一 overview 内容做了完整演绎：`#edeee8` 底、`#151515` 2px 描边、`4px 4px 0` 硬阴影、
陶土/黄/绿色块、Archivo Black 标题。保留比稿以记录判断依据：

1. 声部不合：粗野的海报腔与「安静地替你写配置文件」的产品人格相抵；
2. 暗色不诚实：硬黑阴影在近黑底上消失，只能用亮描边假装，风格骨架在暗色下塌掉一半；
3. 密度预算花错位置：13 行 Agent 的信息密度下，粗框比内容更响。
4. 对比度上它并非不合格（黑字在陶土上 5.46:1 达标；白字在陶土上 3.35:1 不达标，
   故该方向若采用，规则必须是「陶土块上永远用墨字」）。
