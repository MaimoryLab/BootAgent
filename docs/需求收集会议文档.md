# BootAgent 产品需求收集

## 🎯 BootAgent 产品简介

**定位一句话**：本地桌面 AI Agent 配置中心，统一管理多个 AI 编程助手的安装、配置与切换。

**当前支持的 Agent**（13 个 CLI + 5 个桌面）：
- CLI：Codex、Claude Code、Kilo CLI、Aider、OpenCode、Hermes Agent、OpenClaw、Kimi Code、DeepSeek Harness 等
- 桌面：DSH Desktop、Claude Desktop、ChatGPT Desktop、WorkBuddy、ZCode

**核心能力**：
- 检测、安装、更新、启动 Agent
- 连接到内置或自定义 Provider（API 供应商）
- 保存可复用的 Profile（配置档）并一键应用
- 跨 Agent 同步 MCP 服务器配置
- 本地存储凭据，原子写入配置，保留 3 份历史备份
